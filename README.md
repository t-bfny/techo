# techo

Evernote代替の自作メモPWA。PC・スマホ・(将来の)タブレットで同じものを使う。

## 起動

```
npm install
npm run dev      # 開発サーバー(LAN公開)
npm run build    # dist/ に本番ビルド
npm run preview  # ビルド結果の確認
```

## 今できること (v0.2)

- メモの作成・編集・自動保存(端末内のIndexedDB)
- 全文検索(スペース区切りでAND)
- 画像の貼り付け・ドロップ・ファイル選択(長辺2000pxに縮小して保存)
- リンク自動化(日本語の直後のURLも可)
- YouTube URLを貼ると埋め込み(youtu.be の共有リンクも可)
- 表(表の中にいる間だけ 行+/列+/行-/列- が出る)
- 書式ツールバー: 挿入メニュー、元に戻す/やり直し、見出し、太字/斜体/下線/取り消し線、文字色、ハイライト、箇条書き/番号/チェックリスト
- ホーム画面(最近のノートのカード、ショートカット、ノートブック)。起動時とスマホの最初の画面
- ノートブックのページ(各ノートブックを▸で開くと中のノートが並ぶ)
- タスク: チェックリストの項目に期限を付けられる。タスクのページで全ノートのタスクを期限切れ/今日/明日/今後/期限なしに分けて表示し、そこからチェックできる。ホーム画面に今日までのタスク
- ファイル: 挿入メニューからPDFなど任意のファイルを添付。ファイルのページで全ノートの画像・添付を一覧
- ノートブック(件数つき)、ショートカット(ノートとノートブックの両方を登録可)、最近のノート、パンくずからノートブック移動
- タブ: クリックで今のタブを置き換え、中クリックで新しいタブ(PCのみ)
- 一覧の複数選択: Shift+クリックで範囲、Ctrl+クリックで1件ずつ。まとめて削除/ノートブック移動/ショートカット、Deleteキーで削除
- ゴミ箱: 削除したノートは30日保管して自動で完全削除。復元/完全に削除/ゴミ箱を空にする
- Ctrl+Z: 入力中以外は直前のノート操作(削除・移動・ショートカット)を取り消す。画面下の「元に戻す」でも可
- プレビュー: 読み取り専用、大きい文字(A-/A+)、画面が消えない(スタジオ用)
- 書き出し/読み込み(JSONバックアップ。新しい方が勝つ)
- Evernoteの .enex 取り込み(1ファイル=1ノートブック、ファイル名がノートブック名)。v0.15.1から「読み込み」ボタンに統一(.json と .enex を複数まとめて選べる)
  - 少しずつ読むので1GB近いファイルも可。Evernoteの「タスク」はチェックリスト(完了・期限つき)に変換
  - 同じノートは二重に入らない。techoで未編集のノートは再取り込みで新しい変換に置き換わる
- オフライン動作(Service Worker)
- 幅1100px以上は サイドバー|一覧|本文、それ未満はサイドバーを引き出し式に。760px以下は1画面ずつ

## データの形

- `notes`: `{id, title, html, text, notebookId, pinned, createdAt, updatedAt}`
- `notebooks`: `{id, name, createdAt}`
- `attachments`: `{id, blob, type, createdAt}`。本文HTMLでは `att:ID` として参照する

## v0.10 で追加

- テンプレート: ノートを右クリック →「テンプレートとして保存」。「新規作成」でテンプレートを選べる(テンプレートが無いときはすぐ空のノート)
  - タイトルの日付(YYYY-MM-DD)は `{{date}}` として保存し、作るときに今日の日付を入れる
  - 作ったノートはチェックリストが全部未チェック・期限なしで始まる。作成先はテンプレートのノートブック
  - サイドバーの「テンプレート」で一覧・編集・削除。自動生成はしない(本人指定)
- コピーを作成: 右クリックで同じノートブックに「… のコピー」を複製(複数選択可、Ctrl+Zで取り消し)
- テーマ(v0.11): グラファイト(ダーク)/ ペーパー(ライト)/ ボルドー / フォレスト / インディゴ。ホーム画面右上の「テーマ」から選ぶ。未選択のあいだはOSのライト/ダークに合わせる

## セキュリティ(v0.12)

- 取り込み(.enex / バックアップ.json)の本文は DOMPurify で無害化してから保存。印刷・プレビュー・HTML書き出しの直前にも再度無害化(古い取り込み分も守る)
- 埋め込み(iframe)は YouTube のみ許可
- 添付へのリンクは、画像・PDF・音声・動画・テキスト以外は「ダウンロード扱い」(HTML/SVGなどをtechoの中で開かない)
- Content-Security-Policy で、techo自身以外のスクリプト・インラインスクリプトを禁止(public/_headers)

## データを失わないために(v0.13)

- 保存に失敗したら画面上部にお知らせ(「もう一度保存」「書き出し」)。失敗した変更はメモリに残し、タブを閉じようとすると警告
- 空き容量が足りずに保存が打ち切られても固まらない(IndexedDBのabortを拾う)。起動時に容量が9割を超えていれば知らせる
- 最後の書き出しから7日で、起動時に書き出しを促す(iPhoneでホーム画面未追加なら消える可能性も案内)。「あとで」で3日休み
- 別のタブ: 同じノートを開いたら知らせる。別のタブで変わったノートをこちらで上書きしそうなときは保存を止めて「最新を読み込む / こちらで上書き」。一覧は自動で同期

## v0.14 で追加

- 目次: 挿入メニュー →「目次」。見出し1〜3を自動で並べ、押すとその見出しへ移動。見出しを変えると目次もすぐ変わる(保存されるのは目次の置き場所だけで、中身は毎回見出しから作る)
- プレビュー・印刷・HTML書き出しにも目次が出る(HTML書き出しではページ内リンク)
- インデント(v0.14.1): 本文・見出しで Tab / Shift+Tab(最大8段、複数行まとめても可)。行頭の Backspace でも1段戻る。箇条書き・チェックリストは入れ子、表はセル移動、コードブロックはタブ文字。Tabでノートの外にフォーカスが飛ばない

## v0.14.2 書き出しの修正

- 大きなデータ(画像込みで数百MB〜)の書き出しが「Invalid string length」で黙って失敗していたのを修正。1件ずつファイルへ書き込む形式(version 2、1行1レコードのJSON)に変更
- PCのChrome/Edgeでは保存ダイアログで保存先を選べる。それ以外はダウンロードフォルダへ
- 書き出し中は画面上部に進み具合。失敗したら理由と「もう一度」を表示
- 読み込みも1行ずつ読むので大きなバックアップを戻せる。以前の形式(version 1)もそのまま読める

## v0.15 で追加

- 新しいウィンドウで開く: ノートやタブを右クリック →「新しいウィンドウで開く」(PCのみ)。そのノートだけの別ウィンドウ(サイドバー・一覧・タブなし、ウィンドウ名はノートのタイトル)。開くと元のウィンドウのタブからは外れる。削除するとウィンドウが閉じる。URLは `/?w=1#n/ID`
- v0.15.2: 別の端末のバックアップを読み込むとき、同じ名前のノートブック(「マイノート」など)は1つにまとめる。すでに重複して空になっている方は起動時に片付ける

## v0.16 で追加

- ホーム画面の検索窓(Ctrl+K でどこからでも): 入力するそばから、すべてのノートを検索。タイトルに当たったものが先、あとは新しい順。本文の当たった前後を表示して強調。Enterで先頭を開く、↑↓で選ぶ、Escで消す。31件以上は「一覧ですべてを見る」
- 検索はカタカナ/ひらがな、全角/半角、大文字/小文字を区別しない(「せっしょん」で「セッション」、「bpm」で「ＢＰＭ」)
- 一覧の検索でも当たった箇所を強調。ノートブックの中で検索すると、ほかのノートブックの件数と「すべてのノートで検索」を表示
